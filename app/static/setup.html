把设备接入网关

只需把设备的网关与 DNS 指向本机，即可自动分流：国内网站直连、国外网站走代理，无需在每台设备上装软件。

配置约 2 分钟 · 一次设置长期有效

接入原理

你的设备把流量交给网关，网关自动判断：国内直连、国外走代理。

四步完成接入（方式 A：透明网关）

以 Wi-Fi 连接为例（有线连接同理，在「网络适配器」中设置）。此方式要求网关主机已完成「旁路网关配置」。

1
打开 Wi-Fi 设置，改为「静态 IP」
进入当前 Wi-Fi 的详情 → IP 设置 → 由「DHCP / 自动」改为「静态 / 手动」。
IP 地址192.168.1.100
2
网关填本机地址
把默认网关指向网关设备，这是流量分流的关键。
网关192.168.1.10
3
DNS 也填本机地址
DNS 必须指向网关，才能让分流规则生效。
DNS192.168.1.10
子网掩码255.255.255.0
4
保存并测试连接
保存后回到本页，点击下方「测试我的连接」验证是否生效。
切勿把 DNS 填成 8.8.8.8、114.114.114.114 等公共 DNS！
那样会绕过网关的分流规则，导致国外网站无法代理、甚至完全无法上网。DNS 必须填网关地址 192.168.1.10。

方式 B：代理直通（无需改网关，最省事）

如果网关主机暂时未完成旁路网关配置，或你的设备不方便修改网关（如智能电视、部分手机），可直接把设备代理指向网关主机的混合端口，立即生效。

1
在设备上找到「代理 / Proxy」设置
电脑：系统设置里的「代理服务器」；手机：Wi-Fi 详情 → 代理 → 手动；浏览器：可安装 SwitchyOmega 等插件。
2
填入网关主机的代理地址
支持 HTTP 与 SOCKS5 两种协议（同一端口）。
代理服务器192.168.1.10
端口7890
3
保存后即可上网
此方式无需修改 IP / 网关 / DNS，代理流量会自动按规则分流（国内直连、国外走节点）。
这是最快可用的方式。只要网关主机开着，任何设备填上 192.168.1.10:7890 就能立即用上代理，无需任何提权操作。

分平台详细步骤

选择你的设备类型，按步骤操作即可。

点击任务栏右下角 Wi-Fi 图标，选择你的网络，点「属性」。
在「IP 分配」处点击 编辑，把「自动 (DHCP)」改为 手动，打开 IPv4。
填写 IP：192.168.1.100，子网掩码（前缀长度）：255.255.255.0。
网关填 192.168.1.10；首选 DNS 填 192.168.1.10，备用 DNS 留空。
点击 保存，等待几秒后回到本页点「测试我的连接」。
打开 设置 → 网络和 Internet → Wi-Fi，点击已连接的网络名。
下滑到 IP 设置，点击「编辑」，类型选 手动，开启 IPv4。
IP 地址填 192.168.1.100，子网掩码 255.255.255.0。
网关填 192.168.1.10，首选 DNS 192.168.1.10。
点击 保存。若提示无法上网，先忽略，完成测试后再判断。
iPhone / iPad：设置 → 无线局域网 → 点击已连网络右侧的 ⓘ。
下滑到 配置 IP，由「自动」改为 手动。
IP 地址填 192.168.1.100，子网掩码 255.255.255.0，路由器填 192.168.1.10。
下滑到 配置 DNS，改为「手动」，删除原有服务器，添加 192.168.1.10。
点右上角 存储。（macOS 电脑：系统设置 → 网络 → 详细信息 → TCP/IP 手动配置，DNS 同理。）
打开 设置 → WLAN，长按（或点右侧箭头）当前已连接的网络。
选择 修改网络 / 修改网络配置，展开「高级选项」。
把 IP 设置 从「DHCP」改为 静态。
IP 地址填 192.168.1.100，网关填 192.168.1.10，网络前缀长度填 24（即掩码 255.255.255.0）。
DNS 1 填 192.168.1.10，DNS 2 留空，点 保存。（小米 / 华为 / OPPO / vivo 路径基本一致）
适用：不想逐台设备设置，让整个 Wi-Fi 都走网关（需路由器支持自定义网关/DNS）。
浏览器登录路由器管理页（通常 192.168.1.1 或 192.168.0.1）。
在 DHCP 服务 / 局域网设置 中，把「网关」与「DNS 服务器」改为 192.168.1.10。
保存并让路由器 重启 DHCP（或重启路由器），已连接设备需重连 Wi-Fi。
注意：本网关本身应保持直连上级路由（不指向自己），避免环路。
若设备原先能上网、改静态后失败，多半是 IP 与他人冲突或网关填错。换一个不常用的 IP（如 .100 之后）再试。
